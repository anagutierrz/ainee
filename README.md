# Ainee Pimentel — Demo landing page

Static Vercel-ready demo built from the supplied brand assets and brief.

## Run locally

```bash
npx serve .
```

## Deploy to Vercel

From this directory:

```bash
vercel
```

The demo is explicitly set to `noindex, nofollow` via both HTML meta tags and Vercel response headers.
